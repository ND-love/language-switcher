# LaSwitch

LaSwitch — desktop-приложение для Windows, которое помогает исправлять текст, набранный в неправильной раскладке, и переключать язык ввода.

## Возможности

- исправление текста по горячей клавише
- режим "по выделению"
- режим "всё поле"
- работа из системного трея
- сохранение настроек
- подготовка к автоисправлению последнего слова

## Стек

- Python
- PySide6
- keyboard
- pyperclip

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Сборка в exe

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "LaSwitch" main.py
```

Планы

    автоопределение неправильной раскладки

    автокоррекция последнего слова

    восстановление после сна / блокировки Windows

    логирование

    blacklist приложений
